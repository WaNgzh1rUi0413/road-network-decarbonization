# Data inventory and provenance

## Versioned inputs

### `processed/city_features_emissions.xlsx`

This workbook contains the 140-city table used directly by the machine-learning,
SHAP and clustering experiments. `Sheet3` includes city identifiers, country and
continent, ten network descriptors, and normalized emissions for the ten OD
demand levels. It is a processed study dataset and is small enough to remain in
the repository.

### `../network/*-original_{node,link}.csv`

These 280 files are the exact graph inputs used for the reported computations.
Node files contain zero-based node ID and projected x/y coordinates. Link files
contain tail, head, length (m), capacity (vehicles h-1), free-flow time (h), speed
limit (m s-1), and the BPR alpha and beta parameters. The tables are derived from
OpenStreetMap and are subject to the Open Database License (ODbL); attribution:
© OpenStreetMap contributors.

### `../configs/paper_config.json`

This file records the 140 central-city polygons and the paper modeling protocol.
The polygons make the optional OSM acquisition step auditable. Exact numerical
reproduction should use the versioned node/link tables because OSM is dynamic.

### `../k_center/results/original/*_kcenter_k10_binary_search.csv`

These 140 small tables record the exact ten OD centers used for traffic
assignment. They permit downstream reproduction without rerunning the
COPT-based K-center optimization and also guard against non-unique optima.

The average-capacity and average-speed-limit fields used by the paper are
versioned in `processed/city_features_emissions.xlsx`. They were derived before
the final directed assignment-table representation, so the reproduction
workflow does not replace them with simple means of the directed link rows.

### `checksums.csv`

SHA-256 hashes and byte sizes for every versioned scientific input. Run
`python scripts/verify_inputs.py` before an experiment.

## Generated data not committed

The following artifacts are generated by the documented workflows and excluded
from Git because of their size or redundancy:

- K-center solutions and traffic-assignment inputs;
- 1x–10x OD link-flow tables;
- link-level and network-level emission outputs;
- fitted models and scalers;
- SHAP arrays;
- reconstructed networks and their flow/emission outputs.

Together these files can exceed 18 GB. They are reproducible from the versioned
inputs and code. If the journal requires direct access to every intermediate,
archive a tagged copy in a DOI-minting repository and add its identifier here.

## Data Availability text for the manuscript

The processed 140-city feature and emissions table and the exact network inputs
used in this study are provided with the accompanying code repository. The road
networks were derived from OpenStreetMap data (© OpenStreetMap contributors,
available under the Open Database License). Large intermediate traffic-flow,
model and counterfactual-output files can be regenerated using the documented
workflows. The final repository DOI or accession number must be inserted after
the public archive is created.
